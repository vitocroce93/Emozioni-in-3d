# Emozioni-in-3d

Bomboniere, segnaposto e gadget personalizzati da stampare in 3D.

## Struttura

- `modelli/`: modelli parametrici OpenSCAD per bomboniere (portachiavi a cuore, segnaposto con nome) con STL di esempio.
- `progetti/`: lavori su commissione.
  - `pinup-cafe/`: portachiavi aziendale con gettone per carrello. Vedi il [README](progetti/pinup-cafe/README.md).
- `strumenti/`: script di supporto, ad esempio la conversione di un logo in livelli colore stampabili.
